# Goudy initial

`goudy-initial-t.svg` contains the GoudyInitialen letter T by Dieter Steffmann, extracted as a vector from `Classic_Preprint_Template_v1_02.pdf` to match the LaTeX `\initfamily` drop cap. It is a derivative of the font artwork, not part of this repository's MIT-licensed code.

The [CTAN `initials` package](https://ctan.org/pkg/initials) distributes GoudyInitialen under the [LaTeX Project Public License](https://www.latex-project.org/lppl/). The SVG is distributed under that font license.
