# Goudy initial

`fonts/goudy-initialen-web.otf` is a web edition of Goudy Initialen, designed by Frederic W. Goudy and digitized by Dieter Steffmann. The opening letter is text styled with `@font-face`, matching the LaTeX `\initfamily` drop cap.

The web edition converts `GoudyIn.pfb` from the [CTAN `initials` package](https://ctan.org/pkg/initials) to OpenType/CFF. It retains the original copyright notice, glyph outlines, and advance widths. The conversion rebuilds the outline programs without Type 1 hinting, adds a Unicode character map, and gives the converted font a distinct name.

The font is distributed under the [LaTeX Project Public License](https://www.latex-project.org/lppl/). The complete, unmodified source package and its licensing notice are available in the [CTAN archive](https://mirrors.ctan.org/fonts/initials.zip).
